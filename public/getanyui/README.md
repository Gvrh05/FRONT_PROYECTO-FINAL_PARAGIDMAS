# Referencia visual GetAnyUI

Logotipo e icono copiados de la exportación facilitada por el usuario:
`getanyui-20261115233550-profelink-plataforma-de--0bcb`, captura de profelink.com/home.
Se combinaron con las capturas de cabecera/registro/pie de las otras dos carpetas.
La referencia utiliza tipografía sans-serif de sistema: no requiere fuentes remotas.

Solo se reutilizan estos assets y los criterios visuales (fondo oscuro, paneles
pizarra, bordes traslúcidos, acentos azules/violetas). No se importa HTML ejecutable,
scripts, datos personales, trackers ni lógica de la web capturada.
